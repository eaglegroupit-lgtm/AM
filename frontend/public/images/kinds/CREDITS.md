# Photo Credits

The restaurant's own menu cards (in the original request) contained only item
names — no food photography. Since one representative real photo per dish
"kind" was needed (idly, dosa, biryani, etc. — see `src/utils/dishKind.js`
for how each of the 121 items maps to one of these 23 kinds), the following
freely-licensed photos were sourced from Wikimedia Commons. Most require
attribution under their Creative Commons license.

**Before using this site commercially / publicly, either:**
1. Replace these with the restaurant's own photography via Admin → Menu Items, or
2. Keep proper attribution to the photographers below on a credits/about page.
